## How to propose a new decision

Use an issue or PR to state problem, alternatives, affected users, effect on free/local-first/zero-open constraints, religious/technical/privacy dependencies, decision maker, review evidence, and explicit accepted/deferred/rejected scope. Add a dated row only when the decision has actually been made. Do not silently treat a model's suggestion as founder approval.
