## Immediate use

Do not design a mandatory daily dashboard visit, an AI chat front page or ongoing background surveillance. First design and test a zero-open day, a notification-permission-denied day, and offline onboarding, then use the existing 106-state register for remaining detail.

Review the four top-level areas and the four concept wireframes in Part II. Then walk through UF01, UF02, UF04, UF05, UF09, UF11, UF17, UF22 and UF29; these expose most major product risks. Finally work screen by screen from the CSV and use the design handoff prompt to create testable wireframes.
